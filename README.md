# CHAPTER & CO. — Grand Collection: A Chapter by the Sea (V1)

A standalone, responsive wedding invitation demo inspired by the approved coastal wedding concept moodboard.

## Publish on GitHub Pages

1. Extract this ZIP.
2. Upload **the contents** (`index.html`, `style.css`, `app.js`, and `assets/`) directly to your repository's root.
3. In repository Settings → Pages, choose Deploy from branch → `main` → `/ (root)`.
4. Wait for the GitHub Pages deployment to complete. No build step required.

## Interactive features

- Touch-to-open clam with pearl and rings (CSS/SVG animation), followed by animated ocean-wave transition.
- Separate music and SFX buttons. Audio begins only after user interaction, subject to browser autoplay rules.
- Animated scroll reveals and prominent canvas sea-spray, petals, golden sparkles and glowing particles.
- Responsive navigation, love-story timeline, prenup video player, gallery lightbox, countdown, map switcher, dress code and RSVP.
- The video pauses the background music; when video is paused or finished, enabled music resumes.
- RSVP is a local-browser demonstration (localStorage), NOT a submission service.

## IMPORTANT — demonstration assets and data

- Photographs are crops from the **approved reference moodboard**, not individual high-resolution photos. Replace before commercial delivery.
- `assets/video/save-the-date-demo.mp4` is a short demonstration clip, not a genuine prenup film.
- `assets/audio/romantic-placeholder.mp3` is a bundled placeholder. Replace with properly licensed wedding music.
- The example wedding date is February 20, 2027. The Boracay venue names and times are **illustrative**, and map embeds show the approximate island area rather than verified venue pins.
- RSVP responses are stored only in the browser; to collect guest responses, integrate a secure backend or form provider.
- Fonts are fetched from Google Fonts when online, with browser serif/sans fallbacks.

The design is a separate collection and does not modify the approved Modern Romance or Royal Conservatory projects.
